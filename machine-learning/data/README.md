# data/

取得したデータの置き場です(今は空)。学習用は `training_data.npz` として置きます。

| キー | 中身 |
|---|---|
| `normal_x` | 通常時のタイピングの特徴量(オートエンコーダーの学習用)。形は (サンプル数, 特徴量数) |
| `labeled_x` | ストレス・疲労などの特徴量。`normal_x` と同じ特徴量数 |
| `labels` | `labeled_x` の状態ラベル(例: `stress`, `fatigue`) |

特徴量の数は自由です(3次元以上の配列は、サンプルごとに平坦化されます)。
別の場所のファイルを使うときは、環境変数 `ML_TRAINING_DATA` で指定します。
